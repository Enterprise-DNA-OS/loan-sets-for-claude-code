# log

Run `npm run sets -- log <case or hospital> --body= [--kind=call|email|visit|meeting|note]`. Fill in the operator's values. Add `--json` when you need every field.

Log against a case code or a hospital. Keep it to what was said and what was agreed.

Nothing here sends a message or contacts anyone.
