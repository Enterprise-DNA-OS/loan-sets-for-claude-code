# sets

Run `npm run sets -- sets [--json]`. Fill in the operator's values. Add `--json` when you need every field.

Present by status: out at hospitals first, then in transit, then on the shelf. Call out any set short of its kit list or not checked in 30 days.

Nothing here sends a message or contacts anyone.
