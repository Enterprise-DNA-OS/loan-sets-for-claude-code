# expiring

Run `npm run sets -- expiring [--json]`. Fill in the operator's values. Add `--json` when you need every field.

Lead with anything in a set booked to a case. Suggest moving short-dated stock to the busiest location so it is used first.

Nothing here sends a message or contacts anyone.
