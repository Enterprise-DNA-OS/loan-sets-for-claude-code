# bill-case

Run `npm run sets -- bill-case <case> --invoice= [--on=YYYY-MM-DD] [--po=]`. Fill in the operator's values. Add `--json` when you need every field.

Run once the invoice exists in the accounts system. This records the invoice number; it does not raise the invoice.

Nothing here sends a message or contacts anyone.
