# deliver-set

Run `npm run sets -- deliver-set <case> <set> [--at=YYYY-MM-DDTHH:MM]`. Fill in the operator's values. Add `--json` when you need every field.

Record the delivery time the hospital signed for. Use `--at=` when it was not just now.

Nothing here sends a message or contacts anyone.
