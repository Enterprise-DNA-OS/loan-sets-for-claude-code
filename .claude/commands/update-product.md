# update-product

Run `npm run sets -- update-product <sku> [--artg=] [--billing-code=] [--wand=YYYY-MM-DD] [--nz-first-supplied=YYYY-MM-DD] [--price=] [--card=yes|no]`. Fill in the operator's values. Add `--json` when you need every field.

Record the regulatory numbers as they come in. Re-run `compliance` after.

Nothing here sends a message or contacts anyone.
