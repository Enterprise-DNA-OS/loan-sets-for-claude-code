# attention

Run `npm run sets -- attention [--json]`. Fill in the operator's values. Add `--json` when you need every field.

Lead with cases in the next 3 days that have a problem, then anything with days left under 7 or negative. Group by rep if the operator asks "who needs to do what". For a rule finding, name the rule and its source from the row. Offer the matching fix: ship or deliver the set, book a set, a charge chase, a pick list, or quarantine.

Nothing here sends a message or contacts anyone.
