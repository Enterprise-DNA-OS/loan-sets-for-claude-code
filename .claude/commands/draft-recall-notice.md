# draft-recall-notice

Run `npm run sets -- draft-recall-notice <action>`. Fill in the operator's values. Add `--json` when you need every field.

Writes one letter per hospital to drafts/, listing the units it holds and the implanted cases. The regulatory lead fills in the action agreed with the TGA or Medsafe. Never send it.

Nothing here sends a message or contacts anyone.
