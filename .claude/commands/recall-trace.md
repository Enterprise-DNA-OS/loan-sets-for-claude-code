# recall-trace

Run `npm run sets -- recall-trace [--json]`. Fill in the operator's values. Add `--json` when you need every field.

Group by hospital. Stock and sets are to pull; patients' cases are for the hospital to follow up. Offer `quarantine <action>` and `draft-recall-notice <action>`. Treat patient references as confidential: never paste them outside this folder.

Nothing here sends a message or contacts anyone.
