# book-case

Run `npm run sets -- book-case --code=C-1200 --hospital= --on=YYYY-MM-DD [--surgeon=] [--rep=] [--procedure=] [--patient=] [--po=] [--status=booked|confirmed]`. Fill in the operator's values. Add `--json` when you need every field.

Ask for the hospital, the date and the surgeon if they are missing. After booking, offer to assign a set.

Nothing here sends a message or contacts anyone.
