# weekly-review

Run `npm run sets -- weekly-review`. Fill in the operator's values. Add `--json` when you need every field.

Run it, then read the draft it wrote and give the operator the five things that matter this week in plain sentences: cases at risk first, then sets, then money, then rules. Name the draft file.

Nothing here sends a message or contacts anyone.
