# move-stock

Run `npm run sets -- move-stock --from= --to= --sku= --qty= [--lot=]`. Fill in the operator's values. Add `--json` when you need every field.

Record stock moved between warehouse, consignment, rep trunk and quarantine.

Nothing here sends a message or contacts anyone.
