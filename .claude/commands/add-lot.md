# add-lot

Run `npm run sets -- add-lot --sku= --lot= [--expires=YYYY-MM-DD]`. Fill in the operator's values. Add `--json` when you need every field.

Add a lot and its expiry before receiving stock against it, or let `receive` create it.

Nothing here sends a message or contacts anyone.
