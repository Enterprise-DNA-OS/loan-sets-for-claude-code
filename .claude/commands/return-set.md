# return-set

Run `npm run sets -- return-set <set> [--on=YYYY-MM-DD]`. Fill in the operator's values. Add `--json` when you need every field.

Record the set back. Then it needs `check-set` before it can go out again.

Nothing here sends a message or contacts anyone.
