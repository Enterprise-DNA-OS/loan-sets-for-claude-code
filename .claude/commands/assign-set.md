# assign-set

Run `npm run sets -- assign-set <case> <set>`. Fill in the operator's values. Add `--json` when you need every field.

Show the result row. If `clashes_with` is set, say so and offer another set of the same kit.

Nothing here sends a message or contacts anyone.
