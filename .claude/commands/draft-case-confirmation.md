# draft-case-confirmation

Run `npm run sets -- draft-case-confirmation <case>`. Fill in the operator's values. Add `--json` when you need every field.

Writes the email to theatre or sterilising services to drafts/. If it starts with an office note, fix the problem or tell the operator before it goes. Never send it.

Nothing here sends a message or contacts anyone.
