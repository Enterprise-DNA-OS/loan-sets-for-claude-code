# draft-charge-chase

Run `npm run sets -- draft-charge-chase <case>`. Fill in the operator's values. Add `--json` when you need every field.

Writes the email asking for the charge sheet (to theatre) or the purchase order (to accounts) to drafts/. Never send it.

Nothing here sends a message or contacts anyone.
