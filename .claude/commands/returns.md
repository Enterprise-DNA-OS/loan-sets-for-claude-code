# returns

Run `npm run sets -- returns [--json]`. Fill in the operator's values. Add `--json` when you need every field.

For each set still out, give the hospital, the case and the days. Offer a short note to the hospital's sterilising services asking them to release it, as a draft in drafts/ written by you. Never send it.

Nothing here sends a message or contacts anyone.
