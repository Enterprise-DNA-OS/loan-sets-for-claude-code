# utilisation

Run `npm run sets -- utilisation [--json]`. Fill in the operator's values. Add `--json` when you need every field.

Name sets with no cases in 90 days and nothing booked: they are capital sitting on a shelf. Name sets booked back to back that may need a second copy.

Nothing here sends a message or contacts anyone.
