# compliance

Run `npm run sets -- compliance`. Report as a table: rule, record, detail, source. Breached first, then due within 7 days. For each, name the fix: record the ARTG number or billing code with `update-product`, record the WAND notification date, add the missing lot or card on the usage, or `quarantine` an open recall. If a rule in docs/compliance.md looks out of date, say so and stop: the regulatory lead confirms the rule, then you update the doc and the check together. Nothing here is regulatory advice.

Nothing here sends a message or contacts anyone.
